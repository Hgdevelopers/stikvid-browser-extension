# StikVid Browser Extension

A lightweight browser extension for quick access to the official StikVid website.

- Clicking the extension icon opens a small popup.
- The popup includes the StikVid logo and a button that opens https://stikvid.com/ in a new tab.
- The extension does not collect or transmit personal data.

## Install locally (Chrome / Edge)
1. Extract this ZIP.
2. Open your browser's extensions page.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the extracted `stikvid-browser-extension` folder.
