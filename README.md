# StikVid Browser Extension

Quick access to **StikVid**, a collection of TikTok tools and guides available at [stikvid.com](https://stikvid.com/).

Click the extension icon to open a simple popup, then visit the official website with one click.

## Features

* **Quick Access:** Open StikVid directly from your browser toolbar.
* **Simple Popup:** Clean, lightweight interface featuring the StikVid logo.
* **One-Click Navigation:** Open the StikVid website in a new tab.
* **Privacy-Friendly:** The extension does not collect or transmit personal data.

## Installation

1. Download the latest ZIP from the [Releases page](https://github.com/Hgdevelopers/stikvid-browser-extension/releases).
2. Extract the ZIP to a folder on your computer.
3. Open `chrome://extensions/` in Chrome or `edge://extensions/` in Microsoft Edge.
4. Enable **Developer mode**.
5. Click **Load unpacked** and select the extracted extension folder.

## Compatibility

The extension uses Manifest V3. Test compatibility with each browser before publishing it to that browser's extension store.
